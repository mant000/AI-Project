# R3参数训练与R4受控发现协议

2026-11-18：SFT配置在正式训练前固定；GRPO和主对照配置在各自任何输出/更新/路线结果前固定。本阶段完成研究流程，不承诺训练或状态反馈有收益。R1/R2负结果保留，final仍封存。

共用SFT按`sft_v1.json`执行：原始权重重新初始化LoRA，不使用合成pilot适配器。307条grammar严格父子改善样本，2 epochs、154次逻辑优化更新；epoch0/1/2按仅14条单家族validation response NLL选择，选择后才打开40条家族heldout诊断。NLL不等同路线收益；所有家族共享语料的discovery TSP实例，不宣称未见实例泛化。

GRPO按`grpo_v1.json`执行：终点奖励与有界状态辅助两组、优化种子701/702/703，共288个真实生成。两组固定相同的12个父代、同样的终点提示、实例、求解预算、采样种子和共用SFT初始化。训练采样温度1且无top-p/top-k截断，使训练token概率对应实际采样分布；主发现另用固定0.8/0.95/50设置。真实路线改善给主要奖励，状态奖励幅度至多0.02，组内按最小不同终点奖励间距再缩小，不能颠倒不同真实终点奖励的排序。真实同分时模型仍可能提供错误梯度，须记录并单独诊断。未额外惩罚重复程序，以免把多样性收益与状态价值收益混淆。无方差组明确跳过，不能算实际更新。

实现采用[DeepSeekMath原论文4.1节](https://arxiv.org/html/2402.03300v3#S4.SS1)的group-relative advantage、PPO clipped token surrogate及对固定参考的k3 KL估计；本项目是小样本程序优化应用，不是复现原论文训练规模。相同NF4底座同时装载policy和冻结reference小适配器，禁止误更新reference；核验实际优化器/RNG恢复并回滚验证更新。所有优化种子最后一个预定group的适配器都保留，不用开发集选择模型。所有适配器冻结后才做小量真实分支失配诊断，结果不再用于改奖励。

主对照按`main_control_v1.json`：同精度原始Qwen终点基线、共用SFT终点/状态、两种GRPO各三个优化种子的终点/状态，配对发现种子801/802/803，各24输出，共1080输出。交叉组用于区分训练奖励和推理反馈，不把两者同时改变后的效果单独归因于Transformer。共享冻结基线不当作三个训练重复；三优化种子先在发现种子内部平均，不挑最好种子。初始规则与全部生成设置相同。发现、选择、开发池用预声明新实例，各候选按真实路线选；全体45个独立发现程序冻结后才做新dev。只有三次发现重复，统计仅作描述，不能凭单个有利种子宣称成功。

不因负结果继续扩大。若训练仅学会语法、模型价值失真或最终路线无改善，仍完成受控比较并保留原始证据，随后冻结方法进入独立final与报告。任何真实分支信息均标明有限H、共同随机种子和传统后续策略，不能写成Transformer的成功。
