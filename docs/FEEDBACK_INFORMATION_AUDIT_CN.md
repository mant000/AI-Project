# 反馈信息与规则覆盖核查

2026-11-19北京时间。已完成。最新结果目录：`results/feedback-information-audit-v3/`。

本轮仅使用既有R1状态、真实分支、规则、提示相关记录和终点评价，以及此前固定的grammar规则集合。不生成新数据、不调用LLM、不训练、不运行GLS或分支续跑、不读取final。v1/v2是同次审计代码逐步加入表达见证与完整性检查的中间输出，v3是报告使用版本。

## 问题与足够性的标准

这次要检验三个具体问题，而非重新证明整个方法无效：

1. 状态中存在的正收益动作，是否被已用规则选中？已有全边标签和可恢复观测足够直接计算。
2. 未被选中是否因为当前算术接口无法表达？可构造逐案例的合法表达式作存在性检查；这不是寻找泛化新规则。
3. 旧局部分数能否区分旧完整规则的差异？只联查同一原实例与同一规则的既有终点，不混合不同实例的grammar终点。

若局部标签在规则间近乎常数，它就无法在这些记录上提供排序信息。此时增加相关性样本量并不能修复当前接口，不应默认补数据。检验一种修订机制是否改善，需要另行定义修订与目标；本轮没有自动追加这类实验。

## 实际结果

数据为8个原始实例、32个状态、2400条既有实测行动分支。状态、规则和配对不算独立样本。

| 检查 | 结果 |
|---|---:|
| 存在正收益动作的状态 | 7/32 |
| 正收益动作数 | 15 |
| 此前固定的143条grammar规则＋传统参照 | 144条，4608次状态选边 |
| grammar集合选中正收益动作 | 0次 |
| R1保存的不同源码规则 | 67条，2144次状态选边 |
| R1规则集合选中正收益动作 | 0次 |
| R1规则全32状态局部值均为零 | 66/67条 |
| 对照原有保存选边 | 1088/1088完全一致 |

两个规则集合有源码交集，不能将144+67写成211种不同规则。grammar产生48种状态选边向量，R1规则产生9种，源码多样性明显高于行为多样性。两组并非完全没有非零值：grammar有43个负值选边，R1有1个负值选边；所以“没有正收益”与“所有结果全零”必须区分。

### 算术接口是否能表达这些选择

对15个正收益动作，分别用其已观测的归一化距离c，构造合法规则：

```python
-(d / mean_d - c) ** 2
```

15/15条逐案例规则在对应状态选中了目标动作。它只证明当前接口并非完全无法表示这些动作；常数是看过标签后为单个状态构造，不能当作通用规则、发现成功或泛化收益。

15个动作中14个存在“惩罚次数相同、距离更长”的竞争边。这提示偏向长边的规则族可能存在覆盖偏好；这一计数不是所有规则失败原因的因果证明，也不能推出需要统一偏向短边。

### 局部反馈与完整规则结果的既有配对

67条R1规则均有这8个原实例的完整求解记录，每实例2个旧求解种子，共536个规则—实例配对、1072条既有终点路线。局部bank轨迹使用seed17，终点评价使用seed0/1，不能称完全相同轨迹上的因果实验。

- 536个配对中，仅1个配对含非零局部值。
- 44个配对的4个局部状态值全零，完整规则平均终点成绩却不同于传统参照；其中22个改善、22个变差，涉及14条源码规则、6个原实例。
- 这些计数彼此依赖，不是44次独立研究。
- 各程序在这8个实例上的平均终点效果约从变差0.210到改善0.173 gap百分点，但66/67条程序局部分数相同为零。
- 全部67条的描述性Spearman为−0.242，几乎由唯一非零局部程序决定；不将其作为可靠负相关或显著性证据。

**因此，这些旧记录已足以证明：当前局部反馈对这批规则的辨别力严重不足，会漏掉已有的整程表现差异。** 它不能定位唯一原因，也不能证明修订后的状态方法无效。

## 对milestone的含义

原Frozen/SFT后/GRPO后的状态对照仍支持“当前实现没有稳定收益”。SFT本身的收益不检验状态贡献；SFT/GRPO后的受控状态增量比较则是直接负证据。

此次审计进一步发现反馈链的可观察缺口：好动作存在，现有规则没有选到，父子比较无法暴露双方都遗漏的选择；旧局部分数也几乎不能区分整程结果不同的规则。

接下来若提出新方法，应先明确要改的是案例比较对象、行为覆盖、状态覆盖还是标签时域。不能同时改完再将收益归因于其中一项，也不能因现有数据有限就默认扩大训练或求解。本次交付先保留这一明确诊断，不追加CPU实验。
